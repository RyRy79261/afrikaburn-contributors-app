**Pop in to the next Burner Bar event happening on the 9th of February 2023 at Shackleton Brewing Company from 6:30 pm onwards.**

Burner Bar is an opportunity for burners from all over Cape Town to get together and socialise, make new friends, see old ones, and plot and scheme for the burn, or just talk kak. EVERYONE is welcome. Pull in!

**Burner Bar is a fully participant run event, if you want to create one in your area, please go ahead. It is intended to be purely social, with no agenda.**
