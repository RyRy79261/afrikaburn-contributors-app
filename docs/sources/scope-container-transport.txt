Overview
Theme camps ship supplies to AfricaBurn in storage containers. These containers are stored year-round at
various locations in and around the Tankwa, and are transported to a specific spot on-site during build week
before the event.
There are two journey patterns depending on where a container is stored:
(cid:127) Quaggafontein containers (good standing only): One journey — Quagga Storage fi Site
(cid:127) Off-site containers (Danie's, Frans', Cape Town): Two-stage — Original Storage fi Quagga Storage (in
advance), then Quagga fi Site (during build week)
After the event, the reverse happens: Site fi storage location.

Convoys are groups of trucks running together. Capacity measured in 6m units (a 12m container = 2 units).
Delivery slots are time windows across build week (Mon–Fri), defined by AB admins before bookings open.
Camps pick a time slot; AB assigns them to convoys behind the scenes.

The Booking Flow
From the theme camp admin's perspective:
1. Go to container section of TC dashboard
2. See all camp containers with current details and storage locations
3. Click 'Book transport for [Edition Year]'
4. Walkthrough wizard: select containers, confirm details, upload photos, choose post-event storage,
declare priority, choose delivery slot
5. ERF auto-populated from camp profile (if placement confirmed)
6. Nominate mandated collection person (name + phone)
7. Review bundled pricing breakdown per container, pay via Yoco
8. Booking confirmed — all containers show on dashboard with statuses
Confirmed Business Rules
(cid:127) Container sizes: 6m or 12m. Identified by painted code (e.g. JAV-1)
(cid:127) Good standing = 2 active years + cammo paint fi unlocks free Quagga storage
(cid:127) Payment bundled: to-event + from-event + next year's storage, all via Yoco in one transaction
(cid:127) Camp chooses post-event storage location at booking time
(cid:127) A camp can have multiple containers (no limit) — sequential codes (MAH-1, MAH-2, MAH-3)
(cid:127) Camps prefer same convoy but can split across slots
(cid:127) ERF pulled from camp profile (from placement), not entered manually at booking
(cid:127) Theme camp registration must be completed before container booking
(cid:127) Mandated collection person proactively signals 'ready to receive' from central wifi point
(cid:127) Collection person can be the camp lead or alt contact — lightweight access (magic link / PIN)
